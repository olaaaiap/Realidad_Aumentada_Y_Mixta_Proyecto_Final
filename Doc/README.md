# Motion Care
---

Esta app de VR está pensada para ayudar a personas mayores a mejorar su motricidad fina y gruesa, memoria y atención. Con actividades cotidianas súper familiares como cocinar huevos, servir sin derramar o jugar cartas, en tres salas acogedoras: cocina, comedor y sala de estar. Todo con navegación simple, botones grandes, ayuda que se adapta al usuario.
